A concept prototype for a companionship app. The idea is simple: one warm light means the other person is there, one note, and fuzzy time that doesn’t make you anxious.一個陪伴 app 的概念原型。想法很簡單：一盞暖光代表對方在，一句話，還有不讓人焦慮的模糊時間。

Lucinuo Website System

This website. I built it myself to keep everything above in one place.就是這個網站。自己做的，把上面這些東西收在一起。

What內容
A bilingual public website that works on phone and desktop, with a private workspace kept separate.一個雙語、手機和電腦都能看的公開網站，私人工作區另外分開。
Built with怎麼做的
Plain HTML, CSS, and JavaScript, plus GitHub Actions and GitHub Pages. No framework.純 HTML、CSS 和 JavaScript，加上 GitHub Actions 和 GitHub Pages，沒有用框架。
Who did it誰做的
All of it—structure, design, code, and upkeep—is mine.從架構、設計、寫程式到維護，都是我自己來。
Why為什麼
Research, publications, projects, code, and personal tools each need a different amount of explaining and openness.研究、文獻、專案、程式碼和個人工具，需要的說明和開放程度都不一樣。
Outcome結果
Something I can keep maintaining: the site explains, GitHub records the public code.一個我顧得動的系統：網站負責解釋，GitHub 負責記錄公開的程式碼。
