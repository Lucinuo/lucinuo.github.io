03 · Active · 2026–present03 · 持續開發 · 2026–至今

Open implementation公開實作

Lucinuo Website System

A public digital studio connecting research context, formal outputs, selected projects, and open development records.連結研究脈絡、正式成果、精選專案與公開開發紀錄的個人數位工作室。

What內容
A bilingual, responsive public website with a deliberately separate private-workspace boundary.具備雙語響應式體驗，並明確分隔私人工作區的公開網站。
Implementation技術實作
Semantic HTML, shared CSS and JavaScript, GitHub Actions, and GitHub Pages—with no framework or build step.使用語意化 HTML、共用 CSS 與 JavaScript、GitHub Actions 與 GitHub Pages，不依賴框架或建置流程。
Role負責項目
Information architecture, content strategy, interface design, implementation, and maintenance.資訊架構、內容策略、介面設計、技術實作與維護。
Problem問題
Research, publications, projects, source code, and personal tools need different levels of context and access.研究、文獻、專案、原始碼與個人工具需要不同的說明脈絡與存取權限。
Key contribution主要貢獻
One design language, clear public content ownership, responsive layouts, and an explicit privacy boundary.建立一致設計語言、清楚的公開內容分工、響應式版面與明確隱私邊界。
Outcome成果
A maintainable system where Lucinuo explains the work and GitHub documents public implementation.形成可長期維護的系統：Lucinuo 解釋工作，GitHub 記錄公開實作。
