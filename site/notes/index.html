Notes札記

Working ideas, kept precise.仍在工作的想法，也要保持精準。

Short notes on evidence, structure, tools, learning, and the decisions that connect them.關於證據、結構、工具、學習，以及把它們連起來的判斷。

Research · Evidence

Evidence is not the same as direction.證據不等於方向。

A paper can support a node without supporting the whole pathway. A result can matter without telling us what to do next. Good research work keeps these layers separate: what was observed, what is supported, what remains uncertain, and which decision is now justified.一篇文獻可以支持一個節點，卻不代表它支持整條路徑。一個結果可以很重要，也不一定直接告訴我們下一步。好的研究工作會把這些層次分開：實際觀察到什麼、目前支持什麼、還有哪些不確定，以及現在可以合理做出哪個決定。

Build · Tools

Build only what clarifies the next decision.只建造能讓下一個決定更清楚的東西。

A useful tool does not need to display everything it knows. It should reduce the number of choices that compete for attention, preserve the information that matters, and make the next action obvious. Extra visibility is not the same as clarity.有用的工具不需要展示它知道的一切。它應該減少彼此爭奪注意力的選項、保存真正重要的資訊，並讓下一步變得清楚。看見更多，不等於理解得更清楚。

Grow · Bearing

Reflection should reduce work, not create it.反思應該減少負擔，而不是製造工作。

If a reflection system demands daily scores, constant categorization, and a growing dashboard, it can become another obligation. The useful outcome of reflection is smaller: see what is true now, recognize what changed, and choose one next move worth carrying.如果一套反思系統要求每天評分、不斷分類，還要維護愈來愈大的儀表板，它就會變成另一項義務。反思真正有用的成果其實更小：看見現在的真實狀態、辨認什麼改變了，再選出一個值得帶走的下一步。
